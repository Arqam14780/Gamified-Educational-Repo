# Learning Academy

Open `Assets/Scenes/MainMenu.unity` and press Play.

See [the Academy guide](Docs/ACADEMY_GUIDE.md) for the current environment, folder structure, dynamic learning packs, PDF import, controls, references and final-year presentation walkthrough.

Rebuild the saved room with **Tools → Academy → Rebuild classroom** after changing bundled learning content.

The original gallery notes and unused prototype tools are retained under `Archive/Prototype`, outside Unity's import folders.
