# Retired prototype files

These files were removed from Unity's Assets folder after confirming their GUIDs were not referenced by active scenes/assets:

- SampleScene: unused Unity starter scene.
- SceneViewWindow: legacy scene picker with a global DeleteAll PlayerPrefs command.
- Instant Screenshot: old screenshot extension; the academy validation builder now captures the relevant screens.

Original files and `.meta` files are kept here for recovery and attribution. Unity does not compile or import this folder. The legacy third-person demo scene is disabled in Build Settings; its controller/character dependencies remain available.
